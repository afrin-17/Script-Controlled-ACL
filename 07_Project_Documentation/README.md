# Phase 7 - Project Documentation

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Introduction
This project demonstrates the implementation of script-controlled Access Control Lists (ACLs) in ServiceNow.

## Project Objective
The objective is to control access to records based on user roles and the Branch field.

## Technologies Used
- ServiceNow
- Access Control Lists (ACL)
- JavaScript ACL Script

## Custom Table
Table Name:
u_institution_details

## Roles Used
- bb1 – Read
- bb2 – Create
- bb3 – Write
- bb4 – Delete
- Admin – Full access

## ACL Operations
The project implements:
- READ ACL
- CREATE ACL
- WRITE ACL
- DELETE ACL

## Project Outcome
The project demonstrates record-level security by controlling viewing, creating, editing and deleting permissions using roles and ACLs.
