# Phase 4 - Project Planning

## Project Title
Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Plan

### Step 1 – User and Role Creation
- Create the EEE test user.
- Create roles bb1, bb2, bb3 and bb4.
- Assign the required roles to the user.

### Step 2 – Table Creation
- Create the Institution Details table.
- Add all required fields.
- Create records with ECE, EEE and CSE branch values.

### Step 3 – ACL Implementation
- Create READ ACL using bb1.
- Create CREATE ACL using bb2.
- Create WRITE ACL using bb3.
- Create DELETE ACL using bb4.

### Step 4 – Testing
- Test access using different roles.
- Test EEE branch record access.
- Test Admin access.
- Verify create, write and delete permissions.

### Step 5 – Documentation
- Collect screenshots.
- Prepare project documentation.
- Organize all project files phase-wise in GitHub.

### Step 6 – Demonstration
- Record the project demonstration.
- Upload the demo video to Google Drive.
- Add the public Drive link to the project repository.
